\begin{oppgavebox}{3}{}
\begin{itemize}
    \item Definer hva det vil si at en liste med vektorer er lienært uavhengige
    \item Definer hva det vil si at en liste av vektorer er ortogonal og ortonormal
    \item Vis at alle ortogonale lister er lineært uavhengige. Er det samme sant for ortonormale liste?
\end{itemize}

\begin{proofbox}{3a)}{}
En liste med vektorer er lineært uavhengig om den eneste løsningen for likninge
\[
    0 = \sum_{ k=1 }^{ n } \alpha_{k}^{} u_k
\]
er om $ \alpha_{1}^{} = ... = \alpha_{n}^{} =0$ \\

Vi kan også si at en liste med vektorer er lineært uavhengige om for $ k=2, ..., n $, så er 
\[
    u_k \notin span \left( u_1, ..., u_{l-1} \right) 
\]
 

\end{proofbox}


\begin{proofbox}{3 b)}{}
Vi har en liste med vektorer $ \left( u_1, ..., u_n \right)  $. De er ortogonale om 
\[
    \langle u_j, u_k \rangle_{  } = 0 \; for j\neq k
\]
og de er ortonormale om 
\[
    \langle u_j, u_k \rangle_{  } = \delta_{jk}
\]
\end{proofbox}


\begin{proofbox}{3 c)}{}
Anta at $ \left( u_1, ..., u_n \right)  $ er lineært uavhengig. Da finnes det skalarer $ \alpha_{1}^{} , ..., \alpha_{n}^{}  $  slik at 
\[
    0 = \sum_{ k=1 }^{ n } \alpha_{k}^{} u_k
\]
har eneste løsning at $ \alpha_{1}^{} = ... = \alpha_{n}^{}  $ 

Ta så indreproduktet med en annen vektor på begge sider

\begin{align*}
    \langle u_j, 0 \rangle_{  } &= 0\\
    \langle u_j, \sum_{ k=1 }^{ n } \alpha_{k}^{} u_k \rangle_{  } \\
    &= \sum_{ k=1 }^{ n } \alpha_{k}^{} \langle u_j, u_k \rangle_{  } \\
    &= \alpha_{j}^{} =0
\end{align*}

Dermed er en vilkårlig ortogonal liste med vektorer automatisk lineært uavhengig
\end{proofbox}
\end{oppgavebox}
